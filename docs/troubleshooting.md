# 困ったとき

画面に出る文言ごとに、原因と対処を書く。パネルが出ないときは、[README](../README.md) の「困ったとき」を見る。

## 「Git のリポジトリではありません」と出る

Claude Code を開いているフォルダが、Git のリポジトリではない。リポジトリのフォルダで、Claude Code を開き直す。

## 「リポジトリの所有者が違います」と出る

git が、フォルダの持ち主と、いまのユーザーが違うと判断している（Windows で起きやすい）。**警告**: 次のコマンドは、git のグローバル設定を変える。信頼できるフォルダだけで実行する。元に戻すときは、`git config --global --unset-all safe.directory` を実行する（ほかのフォルダの登録も消える）。

```bash
git config --global --add safe.directory <フォルダのパス>
```

## 「取得が時間切れか、git を実行できません」と出る

git が 15 秒以内に終わらなかったか、git を起動できなかった。`git --version` で、git が使えるか確かめる。大きなリポジトリでは、時間がかかることがある。

## 「git の実行に失敗しました」と出る

git が、ブランチの一覧を読むコマンドで、エラーを返した。そのフォルダで `git status` を実行して、エラーの内容を確かめる。

## 「ブランチがありません」と出る

一覧に出せるブランチがない。一覧の下に「ブランチ一覧が長すぎます」と出ているときは、ブランチが多すぎて出せなかった。使っていないブランチを減らす。

## 「commit がまだありません」と出る

このリポジトリには、ブランチがない（commit が 1 件もない）。最初の commit を作る。

## 一番下に「gh 不明」と出る

`gh` が入っていない、ログインしていない、または通信に失敗した。PR 以降の段階が `?` になる。commit や push までの段階は、正しく出る。`gh auth status` で、ログインを確かめる。

## 「リモートなし」「origin なし」と出るのに、リモートがある

push・PR の判定に使うのは、名前が `origin` のリモートだけ。`git remote -v` で、名前を確かめる。別の名前なら、`git remote rename <いまの名前> origin` で変えられる。**警告**: 変えると、ほかの人の手順や設定に影響することがある。確かめてから行う。どちらも、push 以降の段階は `－`（対象外）になり、一番下の行の gh は `対象外` になる。

## 選択肢（提案）が出ない

選択肢は、Claude の返答が人の判断を求めているときだけ出る。次のときは出ない。

- Claude が動いている間（止まってから出る）。
- エラー、拒否、中断で止まったとき。
- 返答が、判断を求めていないとき。
- 選択肢を作る呼び出しが失敗したとき、または 30 秒以内に答えが返らなかったとき（ゴールも前回のまま残る）。

## 「正確な数え直しに失敗しました」と出る

「正確に数える」で、トークン数を数える Claude の API の呼び出しに失敗した。内訳は `概算` のまま出る。少し待ってから、もう一度押す。

## 「定型文を保存できませんでした」と出る

定型文の変更を、次のセッション用の保存先に書けなかった。画面の一覧は変わっているが、Claude Code を閉じると元に戻る。もう一度、追加・削除・並び替えをする。続くときは、Claude Code を新しく起動する。

## 「質問や許可の待ち中です。先に答えてください」と出る

Claude が質問や許可の確認を出して、答えを待っている。その間は、次へ進むボタン、リリースの `▶ リリースする`、提案、定型文の「▶ 送信」を押しても、何も送らない。質問や許可に答えてから、もう一度押す。

## 「依頼を送れませんでした」と出る

Claude に依頼を送る呼び出しが失敗した。次へ進むボタンと提案は、もう一度押せる。続くときは、Claude Code を新しく起動する。

## 「Git タブを更新できませんでした」と出る

更新の途中で、予期しない失敗が起きた。「Git」タブを押し直す。直らなければ、Claude Code を起動し直す。
